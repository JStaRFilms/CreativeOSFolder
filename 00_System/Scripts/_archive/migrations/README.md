# Migration Scripts Archive

These scripts were used for one-time data migration and historical maintenance tasks.

## Archived Files

- `migrate_assets.ps1` - Asset migration script
- `migrate_creative_os.ps1` - CreativeOS migration script
- `migrate_projects.ps1` - Project migration script
- `migration_edit_script.ps1` - Migration editing utility
- `retrofit_projects.ps1` - Project retrofitting script
- `MigrateThumbnails.ps1` - Thumbnail migration script
- `delete_trickplay_files.ps1` - trickplay file cleanup
