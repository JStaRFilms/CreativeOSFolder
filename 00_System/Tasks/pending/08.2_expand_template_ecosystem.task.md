### Template Format

Each template is a folder containing `structure.json`:

```json
{
  "00_Notes": ["Brief.md", "Tasks.md"],
  "01_Assets": ["Fonts", "Icons"],
  "02_Exports": []
}
```

String values = **files** to create.  
Nested string values inside arrays = **subfolders** if they have no extension, **files** if they do.

### Variable Substitution (New Feature)

`cmd_new()` should replace these tokens inside `.md` file content after copying:

| Token | Replaced With |
|-------|--------------|
| `{{PROJECT_NAME}}` | The project name as entered |
| `{{DATE}}` | Creation date (`YYYY-MM-DD`) |
| `{{CLIENT}}` | Client name (from `--client` flag, or `"N/A"`) |
| `{{TYPE}}` | Project category (e.g., `"Design"`) |

### Variable Substitution Implementation

In `cmd_new()` (or `cos/commands/new.py`), after copying the template:

```python
def _apply_template_variables(project_path: Path, name: str, project_type: str, client: str) -> None:
    """Replace {{VARIABLE}} tokens in all .md files after template copy."""
    replacements = {
        "{{PROJECT_NAME}}": name,
        "{{DATE}}": datetime.date.today().isoformat(),
        "{{CLIENT}}": client or "N/A",
        "{{TYPE}}": project_type,
    }
    for md_file in project_path.rglob("*.md"):
        try:
            content = md_file.read_text(encoding="utf-8")
            for token, value in replacements.items():
                content = content.replace(token, value)
            md_file.write_text(content, encoding="utf-8")
        except Exception as e:
            log.warning(f"Could not apply variables to {md_file}: {e}")
```

Call this function immediately after the template copy step in `cmd_new()`.
