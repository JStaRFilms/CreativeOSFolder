# 🎯 Task: Lightweight CreativeOS GUI (FastAPI + Vite)

**Objective:** Build a lightweight, PWA-installable web-based GUI for CreativeOS that wraps the existing Python CLI logic.
**Priority:** High
**Scope:** Included: Dashboard, Project Cards, Storage Overview, New Project Form, Settings view. Excluded: File explorer/browsing, editing metadata, archive/resurrect operations.

---

## 📋 Requirements

### Functional Requirements
- **[REQ-001]** Dashboard showing project cards with name, category icon, created date, and active/stale status.
- **[REQ-002]** Storage Overview table showing sortable project storage data (total, media, reclaimable).
- **[REQ-003]** New Project form to create projects via GUI (using existing `cos new` logic).
- **[REQ-004]** `cos gui` command to launch the local FastAPI server and open the default browser.
- **[REQ-005]** PWA support (manifest + basic service worker) so users can "Install" the app from the browser.

### Technical Requirements
- **[TECH-001]** Backend: FastAPI + uvicorn serving as a thin API wrapper over existing `cos` Python modules.
- **[TECH-002]** Frontend: Vanilla HTML/CSS/JS bundled with Vite (no React/Vue needed unless absolutely required for state management).
- **[TECH-003]** Minimal dependencies: Only add `fastapi` and `uvicorn` to Python requirements. No Electron.
- **[TECH-004]** Design: Clean UI, Light/Dark mode toggle. Neutral palette (grays, whites, blacks, subtle blue accents). No purple gradients.
